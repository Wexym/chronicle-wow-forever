# Летопись (Chronicle) — аддон для WoW Forever

Одно окно с вкладками: заметки на игроков, чеклист с авто-сбросом, статистика, дневник, обзор всех персонажей, цели, список желаемых предметов, напоминания, окно для стрима, хардкор-панель и быстрые ссылки на Wowhead Forever.

> **English, in short.** *Chronicle* ("Летопись") is a single-window addon for **World of Warcraft Forever** (Classic-based) with tabs: player notes, daily/weekly/monthly checklist, statistics, journal, alts overview, goals, wishlist, reminders, stream overlay, hardcore panel and Wowhead Forever link helper. The interface is currently **Russian only** (ruRU); all strings live in `Chronicle/Locale/ruRU.lua`, so adding a translation is straightforward. Installation: copy the `Chronicle` folder to `World of Warcraft/<client folder>/Interface/AddOns/` — see below. MIT license.

Работает внутри игры, ничего не скачивает из интернета, не автоматизирует бой и не трогает защищённые элементы интерфейса Blizzard. Все данные хранятся локально в файлах SavedVariables.

## Что внутри

Окно открывается командой `/chron` (запасная — `/летопись`) или кнопкой у миникарты. Его можно перетаскивать за заголовок, менять размер за правый нижний угол, закрывать по Esc. Положение, размер и последняя вкладка запоминаются. Окно работает в бою. Если вкладки не помещаются в один ряд, они переносятся на второй.

| Вкладка | Что делает |
| --- | --- |
| **Игроки** | Заметки на других игроков: отметка (хороший / нейтральный / избегать), роли, теги, текст. Класс, уровень, раса и гильдия обновляются сами, когда игрок в цели или в группе. Отметка и первая строка заметки видны в подсказке над игроком. Предупреждение в чате, если в вашу группу вступил игрок с красной отметкой. Поиск по имени, тегам и заметке, фильтры по отметке, роли и классу. Пункт «Заметка Летописи» в контекстном меню игрока. |
| **Чеклист** | Задачи на день, неделю и месяц. Сбрасываются сами по времени сервера, пропущенные сбросы применяются при входе. Задачи для одного персонажа или для всего аккаунта, счётчики вида 3/5, шаблоны, режим «Альты» (таблица задач × персонажи). Таймер до сброса и время сброса по Минску и по серверу. |
| **Статистика** | Время в игре, опыт и опыт в час, золото (получено / потрачено / итог), убито мобов, сданные квесты, добыча (в том числе редкая и выше), смерти, подземелья и рейды, опасные моменты, выполненные задачи чеклиста. За сессию, день, неделю (7 дней) и месяц (30 дней), по одному персонажу или по всем. Столбиковый график за 7 или 30 дней. |
| **Журнал** | Личный дневник с заголовком, тегами и текстом. Автозаписи: новый уровень, смерть (с указанием, кто убил), первое убийство босса, эпический предмет, достигнутая цель, полученная хотелка. Быстрая запись одной строкой, поиск, фильтры, экспорт текста для копирования. |
| **Альты** | Сводка по всем персонажам аккаунта: уровень, золото, где и когда вышел из игры, профессии, накопленный бонус отдыха (для вышедших из игры это оценка). |
| **Цели** | Долгие цели с полосой прогресса: накопить золото, поднять навык профессии, достичь уровня, свой счётчик. Достижение цели фиксируется само. |
| **Хотелки** | Предметы, которые вам нужны, с источником (босс, подземелье, профессия). Пометка в подсказке предмета, галочка и запись в журнале при получении. |
| **Напоминалки** | Сообщение по центру экрана, когда закончился бафф из вашего списка, почти заполнились сумки, броня скоро сломается или готова перезарядка заклинания. |
| **Стрим** | Маленькое прозрачное окно поверх экрана с крупными цифрами: смерти, вайпы, время боя, золото за сессию. Перетаскивается, масштабируется, может быть «прозрачным для мыши». |
| **Хардкор** | Для хардкорных персонажей: счётчик «опасных моментов» (здоровье ниже порога) с журналом и предупреждение о мобах заметно выше вас по уровню. |
| **Wowhead** | Из игры нельзя открыть сайт, поэтому аддон показывает окно с готовой ссылкой на Wowhead Forever для копирования (Ctrl+C): по ID предмета, квеста, NPC, заклинания, зоны, объекта, ссылки на гайды классов, калькулятор талантов, страницы профессий. Клавиша (по умолчанию Ctrl+Shift+W) даёт ссылку на то, что под курсором. |
| **Настройки** (шестерёнка) | Масштаб окна, кнопка у миникарты, предупреждения, автозаписи журнала, очистка данных каждой вкладки (с подтверждением). |

## Установка

### Что нужно

- Установленный клиент **World of Warcraft Forever** (на момент написания — бета, папка клиента `_classic_beta_`; после релиза она может называться иначе, например `_forever_`).
- Папка **`Chronicle`** из этого репозитория.

### Способ 1. Скачать архив (проще всего)

1. На странице репозитория нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.
2. Внутри будет папка **`Chronicle`** (в ней лежит файл `Chronicle.toc`). Именно **её** нужно скопировать, а не всю распакованную папку проекта.
3. Вставьте её в папку аддонов клиента. Например:

   ```
   D:\Battle.net\World of Warcraft\_classic_beta_\Interface\AddOns\
   ```

   Если папки `Interface` или `AddOns` нет, создайте их.
4. Проверьте, что получился такой путь (файл `.toc` лежит прямо в `Chronicle`, без лишней вложенности):

   ```
   ...\Interface\AddOns\Chronicle\Chronicle.toc
   ```

5. Запустите игру (или перезапустите, если она была открыта). На экране выбора персонажа нажмите **«Дополнения»** (AddOns) и убедитесь, что «Летопись» включена.
6. Если аддон отмечен как устаревший, включите галочку **«Загружать устаревшие дополнения»**.

### Способ 2. Через git (если планируете обновляться или править код)

```bash
git clone https://github.com/Wexym/chronicle-wow-forever.git
```

Чтобы не копировать файлы после каждого обновления, свяжите папку аддона с клиентом символической ссылкой (junction). Команда для `cmd` (подставьте свои пути):

```
mklink /J "D:\Battle.net\World of Warcraft\_classic_beta_\Interface\AddOns\Chronicle" "C:\путь\к\chronicle-wow-forever\Chronicle"
```

После `git pull` достаточно набрать в игре `/reload`.

### Обновление

Замените папку `Chronicle` новой версией. Ваши данные лежат отдельно (см. [Где хранятся данные](#где-хранятся-данные)) и при замене аддона сохраняются.

### Удаление

Удалите папку `Chronicle` из `AddOns`. Чтобы убрать и сохранённые данные, удалите файлы `Chronicle.lua` из папок `SavedVariables` (пути ниже).

## Первые шаги

1. Войдите в игру и введите **`/chron`** (или нажмите на кнопку с книгой у миникарты).
2. Откройте вкладку **«Игроки»**, выберите в цель любого игрока и нажмите «Добавить»: появится заметка.
3. В **«Чеклисте»** нажмите «Шаблоны» и добавьте типовые задачи.
4. На вкладке **«Хардкор»** включите режим, если играете хардкорным персонажем (на персонажах с признаком хардкора клиент может включить его сам).
5. Всё остальное работает автоматически: статистика и журнал начнут наполняться сразу.

## Команды

| Команда | Что делает |
| --- | --- |
| `/chron`, `/летопись` | Открыть или закрыть окно |
| `/chron note [Имя]` | Заметка на игрока (без имени — на цель) |
| `/chron j текст` | Быстрая запись в журнал (без текста — открыть окно быстрой записи) |
| `/chron want [ссылка на предмет]` | Добавить предмет в «Хотелки» (введите команду и shift-кликните по предмету) |
| `/chron wh item 286989` | Ссылка Wowhead; тип: `item`, `quest`, `npc`, `spell`, `zone`, `object` (можно вставить ссылку на предмет из игры) |
| `/chron stream` | Показать или скрыть окно стрима |
| `/chron auto level\|death\|boss\|epic\|goal\|wish on\|off` | Включить или выключить автозапись журнала |
| `/chron weekly день час` | Запасной день и час недельного сброса, если клиент не отдаёт их сам (день: 1 — воскресенье … 7 — суббота) |
| `/chron diag` | Диагностика: версия клиента, какие функции и шаблоны есть, время сервера |
| `/chron reset` | Вернуть окно в центр экрана и размер по умолчанию |

## Где хранятся данные

Аддон использует два файла SavedVariables:

- на весь аккаунт: `World of Warcraft\<папка клиента>\WTF\Account\<АККАУНТ>\SavedVariables\Chronicle.lua`: заметки, журнал, статистика, цели, хотелки, напоминалки, настройки;
- на каждого персонажа: `...\WTF\Account\<АККАУНТ>\<Сервер>\<Персонаж>\SavedVariables\Chronicle.lua`: положение окна, задачи «этот персонаж», окно стрима, хардкор, текущая сессия.

Игра записывает их при выходе и при `/reload`. Чтобы сделать резервную копию, достаточно скопировать эти файлы. Перед обновлением версии структура данных мигрируется автоматически, данные не теряются.

## Если что-то не работает

1. Введите **`/chron diag`** — команда покажет, какие функции и шаблоны есть в вашем клиенте, и время сервера.
2. Установите **BugSack** и **BugGrabber** (любой менеджер аддонов или CurseForge). Они собирают ошибки Lua. Сообщая о проблеме, приложите текст ошибки целиком.
3. Окно потерялось за краем экрана: `/chron reset`.
4. Аддона нет в списке: проверьте путь (`AddOns\Chronicle\Chronicle.toc`), включите «Загружать устаревшие дополнения», убедитесь, что номер интерфейса в `Chronicle.toc` совпадает с вашим клиентом (`/dump select(4, GetBuildInfo())`).
5. Создайте **Issue** в репозитории: опишите, что делали, что ожидали и что получилось, укажите версию клиента (`/chron diag`).

## Известные ограничения

Аддон создан и проверялся на бета-клиенте Forever (сборка 1.60.1), автоматических тестов нет, проверка велась вручную в игре. Из того, что может отличаться на вашем клиенте:

- **«Первое прохождение подземелья»** в журнале сведено к «первому убийству босса подземелья» (требует событий `ENCOUNTER_END` / `BOSS_KILL`).
- **Вайпы в окне стрима** считаются только по событиям боссов. Время боя считается по ним же, а если их нет — по входу в бой и выходу из него.
- **Профессии** читаются разными способами в зависимости от клиента. Если вкладка «Альты» не показывает ваши профессии, пришлите вывод `/chron diag`.
- **Бонус отдыха** у вышедших из игры персонажей — оценка по формуле Classic (5% уровня за 8 часов в городе/таверне и за 32 часа в поле).
- **Гайды Wowhead** по специализациям и профессиям записаны списком в коде и содержат только те, что существуют на сайте на момент проверки; новые добавляются вручную.
- Рядом с серверным временем всегда показывается время **по Минску (UTC+3)**: оно записано в коде, отдельной настройки пока нет. Чтобы заменить его своим часовым поясом, поменяйте смещение `MINSK_OFFSET` в `Chronicle/Core/Utils.lua` (и в `Chronicle/Modules/Journal.lua`, где по нему группируются записи по дням).
- Интерфейс только на **русском**. Добавление другого языка описано в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Для разработчиков

Структура проекта, как добавить свою вкладку, схема данных и правила кода: **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**. История изменений: **[CHANGELOG.md](CHANGELOG.md)**.

Pull request-ы и Issue приветствуются. Перед отправкой:

- проверьте изменения в игре и убедитесь, что в BugSack нет новых ошибок;
- строки интерфейса добавляйте только через `Chronicle/Locale/ruRU.lua`;
- не вызывайте защищённые функции Blizzard и не трогайте их фреймы.
